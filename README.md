# Career Archipelago 🏝️

A Three.js developer portfolio for **Harshal Rathore** — Full-Stack Engineer · Azure-certified.

Scroll-driven cinematic journey through seven floating islands, one per career chapter, as the world's light evolves from golden hour to starlit night. Built with React Three Fiber. No bloom. No slop.

> **Status:** scaffold phase — the archipelago is forming. See open tickets for the build plan.

## Stack

Vite · React 18 · TypeScript strict · @react-three/fiber · drei · zustand · Tailwind · Vitest

## Development

```bash
npm ci
npm run dev        # local dev server
npm test           # vitest
npm run lint       # eslint
npm run typecheck  # tsc strict
npm run build      # production build
npm run preview    # serve dist/
```
